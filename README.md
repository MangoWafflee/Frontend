# 📌 멋쟁이 사자처럼 12기 해커톤

## 💬 소개
SmileHub는 카메라를 통해 웃음을 인식하고 기록하는 웹 애플리케이션입니다.   
 사용자는 웃음을 기록하며 다양한 챌린지에 참여하고 업적을 달성할 수 있습니다.   
 또한, PWA(Progressive Web App) 기술을 활용하여 앱과 유사한 환경을 제공하여, 어디서든지 편리하게 사용할 수 있도록 설계되었습니다.   
<a href="https://hahasmile.netlify.app">   서비스 URL</a>
